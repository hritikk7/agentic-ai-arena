# Agentic AI Arena

A personal playground for building and tinkering with AI agents using LangChain and LangGraph — tool calling, structured outputs, and multi-step agent workflows.

## Setup

```bash
uv sync
cp .env.example .env  # fill in your own API keys
```

## Projects

- `expense_tracker_agent/` — agent that reads transactions from a CSV, categorizes spending, totals by category, and flags unusual transactions.
